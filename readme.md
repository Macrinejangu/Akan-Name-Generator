# Akan Name Generator

## Description
The Akan Name Generator is a simple web application that calculates the day of the week a user was born based on their birthdate and assigns them an Akan name from Ghanaian culture. Akan names are given based on the day of the week a person is born and their gender.

Behavior-Driven Development (BDD)
- Given: a user enters a valid birthdate and selects a gender
- When: the user submits the form
- Then: the app calculates the day of the week and displays the correct Akan name
